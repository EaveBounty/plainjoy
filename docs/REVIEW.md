## 4. 模拟用户旅程（录播）

环境：Chromium headless，390×844，DPR 2，Flutter Web release。

| 时间 | 步骤 | 观察 | 优化 |
|---|---|---|---|
| 0.0–3.2 s | 冷启动 → 开屏 | 三角框、清欢、诗句、茶盏依次出现；无字体方框 | 动画 560 ms；三角内留白足够 |
| 3.2–8.4 s | 开屏停留 | 演示用 5 s 闸门（已恢复 620 ms） | 正式版 TTI 目标 <1.6 s |
| 8.4 s | 首启第 1 屏 | 千金要方引文 + 4 条信息块；一屏读完 | 文案密度符合「没耐心」场景 |
| 点击下一步 | 画风选择 | 两套宠物预览；「清晰」一度因 CDN 字体范围缺字 | Android 系统字体无此问题；Web 需字体自托管 |
| 点击下一步 | 精度选择 | 三档误差区间清楚 | 无 |
| 点击开始 | 首页 | 宠物、今日分数（记录不足）、快速记录入口 | 空状态文案明确 |
| — | 记录一餐 | 搜索 1800 条，输入无卡顿 | 索引后 <1 ms/键（桌面） |
| — | 评分详情 | 「为你的情况」卡片优先展示病况建议 | 新增 |
| — | 食谱展开 | 钠账本显示 Top 来源与盐换算 | 新增 |

未覆盖：真实相机、系统返回手势、TalkBack、深色系统、360×640 小屏（已静态审查，未跑 golden）。
