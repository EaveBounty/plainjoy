Plainjoy有味清欢 (Youwei Qinghuan) — nutrition logging and next-meal planning, without a scale

In short: Plainjoy is a nutrition log that never asks you to weigh food. Photograph a meal or type one sentence, and it rewrites your daily targets around your health condition — then plans only the next one to five meals.

What it is
An Android-first nutrition log and next-meal planner that keeps data on the device. Log a meal, get 16 scored dimensions, one recommendation worth doing, and a patch plan.
Who it is for
People with no patience for weighing, who eat takeaway or canteen food, and who have a real constraint: hypertension, diabetes, gout, chronic kidney disease, anaemia, lactose intolerance, vegetarian diet, pregnancy or breastfeeding.
What it replaces
The weigh-then-fill-the-form calorie logging loop, and the 21-meal perfect-week plan nobody keeps. It does not replace a doctor, a dietitian or medication.

02 / Differences

Three differences; everything else is detail

If you only read three things: how portions are estimated, where targets come from, and how granular the plan is.

  1. One · Portions

    No scale — and the error is stated out loud

    Three precision modes: 10 seconds (container plus reference object, ±35–45%), 60 seconds (swap containers, subtract leftovers), 3 minutes (decompose a mixed dish). Each entry stores a nutrient snapshot, so a later database swap cannot rewrite history.

    Source: README §2.1. The error range comes from literature and common containers; 50–100 real weighings of calibration are still outstanding (README §6).

  2. Two · Targets

    Targets follow the condition, not a brochure

    Ten conditions rewrite daily targets, scoring weights and advice. Hypertension caps sodium at 2000 mg and weights sodium ×1.8; chronic kidney disease uses 0.8 g/kg protein (1.1 g/kg on dialysis) and a 2500 mg potassium ceiling. With several conditions, ceilings take the stricter value, floors take the higher one, and conflicts keep the ceiling with a written reason.

    Source: docs/PERSONALIZATION.md §2–§3. Every number is a dietary target, not a prescription.

  3. Three · Plan

    Only the next 1–5 meals

    The plan is gap-driven and solved deterministically; the language model only narrates the result, it never decides what you eat. You add one or two things to the way you already eat instead of rearranging a whole week.

    Source: README §2.3, lib/core/plan/plan_engine.dart.

04 / Fit

Who it fits, and what it deliberately does not do

Stating the non-fit cases is more useful than ten selling points.

It fits

  • You eat mostly home-style Chinese food, takeaway or canteen meals, and cannot weigh them by the gram.
  • You have a concrete dietary constraint (hypertension, diabetes, gout, CKD, anaemia, lactose intolerance, vegetarian, pregnancy, breastfeeding) and need targets that move with it.
  • You do not want an account, and you do not want diet and health data in someone else's cloud.
  • You accept a range instead of an exact kilocalorie.
  • You want one thing to fix, not a 21-meal table.

It does not fit

  • You need prescriptions, drug doses, dialysis schedules or a clinical nutrition consult.
  • You need gram-exact numbers for competition prep or strict post-surgical tube feeding.
  • You expect cloud sync and multi-device, multi-person family accounts.
  • You need measured fatty-acid splits, purine in mg, or iodine content — the public seed set has none of those fields.
  • You want to download an APK right now: there is no release, you build it yourself.

07 / FAQ

Seven questions people actually type

Answers only claim what the repository can support. Where it is uncertain, it says so.

Is Plainjoy open source?

No. It ships under the PolyForm Noncommercial License 1.0.0, which is not an OSI-approved open source licence. Personal, research and non-commercial use is free; any commercial use needs a separate written licence, described in COMMERCIAL.md.

How inaccurate is portion estimation without a scale?

About ±35–45% in the 10-second mode (source: README §1). That range does not mean anything goes: one meal cannot overturn a verdict, because scoring looks at the 7-day structure and reports a p10–p90 interval. The range currently comes from literature and common containers; 50–100 real weighings of calibration have not been done yet.

Which health conditions are supported?

Ten: hypertension, diabetes, pre-diabetes, gout and hyperuricaemia, chronic kidney disease (with a dialysis switch), anaemia, lactose intolerance, vegetarian diet, pregnancy and breastfeeding (source: docs/PERSONALIZATION.md §2). Conditions change targets, scoring weights and advice order; stacked conditions resolve to the stricter ceiling. Output never includes a diagnosis, a drug dose or a disease-risk percentage.

Do I need the internet or an AI key to log a meal?

No. One-sentence parsing runs on local rules, so logging, scoring and the patch plan all work without an API key; search uses the local seed set (102 foods and 22 condiments). Only photo recognition needs your own DeepSeek key, explicitly enabled, and the request carries just the current input and food names — not your health profile.

Is my diet and health data uploaded anywhere?

Not by the app. Data lives in a local on-device database with no registration or login; on Android, allowBackup is false and both cloud backup and device transfer exclude the database; exports are JSON and hold no API key. Known limitation: the API key is currently stored in plain local settings, and moving it to the Android Keystore is scheduled for the next version.

Does the repo include the full food composition table?

No. The 1,677-entry table is an optional local data pack, not distributed with the repository; the public repo ships 102 independent approximations, 22 condiment ranges and 30 recipes. It must never be uploaded inside an APK, AAB or web build — prepare it from a lawful source and import it locally (docs/DATA.md).

How do I install it — is there an APK download?

There is no download button: the repository has no GitHub Release and no distributed installer. Clone the source and build it with the commands below; release signing needs your own keystore, since the signing config in the repo is gitignored.

How do I log meals without weighing anything?

Use containers, references and leftovers instead of a scale: calibrate one bowl and one spoon, then record low/medium/high and what was left. A meal takes about 10 seconds and portions are stored as ranges (±35–45%); a single estimate cannot overturn the verdict because scoring reads the 7-day structure.

How can I estimate food weight without a scale?

Three anchors: your own containers (bowl, spoon, takeaway box), visual references (palm, egg, bank card, fist) and the net weight on packaging. Store a range such as “rice 120–160 g” rather than a false single point.

What should I look for in a hypertension diet app?

Three things: a sodium ceiling in the targets (≤2,000 mg, ideally 1,500), separate logging for hidden sodium in light soy sauce, dark soy sauce, oyster sauce and MSG, and scoring weights that change with the condition. Plainjoy does all three and converts sodium into grams of salt.

What matters in a kidney-disease diet app?

Protein must follow body weight and dialysis status (commonly 0.6–0.8 g/kg non-dialysis, 1.0–1.2 g/kg on dialysis), potassium and phosphorus ceilings must follow lab results, and potassium-containing salt substitutes need caution. Plainjoy offers a dialysis switch and K/P ceilings, but only as a logging aid — your nephrologist sets the targets.

Can a gout diet app replace a doctor? What should I eat with high uric acid?

No. Logging helps you spot stacking: organ meat, rich broth, beer and sugary drinks in the same day. Prioritise water, low-fat dairy and vegetables, and shift protein toward eggs, dairy and selected fish or poultry. Acute red, hot, swollen joints need medical care, not diet alone.

What should a pregnancy nutrition app track, and how do I start?

Start with five numbers: folate 600 μg DFE, iron 27 mg, calcium 1,000 mg, iodine 230 μg and protein +20 g. Log normal meals and note whether iodised salt is used, then look at gaps. Supplement doses are prescribed by your clinician; the app never gives a dose.

Which local-first diet tracker apps do not upload health data?

Plainjoy is one: data lives in a local Sembast database with no account or login, Android auto-backup is off, and AI is optional and receives only the current input, never the health profile. For any other tool, check its privacy policy, backup behaviour and AI request scope.

How accurate is photo nutrition recognition, and how do I set up DeepSeek?

The photo only identifies the dish and a portion range; nutrients are resolved against the local table first. Only when a dish is missing locally does the app accept an AI per-100 g estimate, marked ai_estimate. Setup: enter the DeepSeek base URL, model and key in Settings, then explicitly enable AI; without a key it falls back to local rules.

08 / Quick start

From clone to running in four commands

Environment: Flutter 3.44.3 / Dart 3.12.2 (do not upgrade blindly — some dependencies require Dart 3.13), Android SDK, JDK 17.

  1. Clone and fetch dependencies

    git clone https://github.com/EaveBounty/plainjoy.git
cd plainjoy
flutter pub get

  2. Run on a device

    flutter run -d <device>

    Works offline: the seed data ships with the repo, and a missing local dataset silently falls back to 102 entries.

  3. Build an Android package

    flutter build apk --release --split-per-abi
# output: build/app/outputs/flutter-apk/app-*-release.apk

    Release signing reads android/key.properties (gitignored). Back up the keystore and passwords offline — lose them and you cannot ship an upgrade.

  4. Check your work

    flutter analyze   # 0 errors
flutter test      # 16/16

    Run these two before talking about screenshots or a release.
