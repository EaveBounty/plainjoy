## 4. 法务边界（不是法律意见）

- 单个营养成分数值通常属于事实，不受著作权保护；但**整表的选择、分类、编码与编排**可能构成汇编作品。
- 本仓库因此只公开：代码、种子估算、统计 manifest、以及**不包含具体数值**的说明。
- 全量库仅本地使用；**任何含该文件的 APK/AAB/Web 产物都不得上传**到 GitHub Release、Actions artifact、Pages、网盘或应用商店。
- 若要公开分发全量数据，需要取得出版方/权利人关于「结构化数据用于 App 打包与分发」的书面授权。
- 公开仓库的 CI 构建必须在不含 `assets/private/cn_food_full.json` 的干净检出上完成。

## 5. 复现

```bash
# 1) 准备合法来源的 merged_*.json 目录
python tool/import_cfct.py --input-dir /path/to/merged_json_dir
# 输出 assets/private/cn_food_full.json + assets/data/cn_food_manifest.json

# 2) 生成调味品表
python tool/generate_condiments.py

# 3) 公开构建自检
./tool/check_public_build.sh
```

## 6. 已知缺口

1. 碘：只有加碘盐/低钠盐两条记录；海带紫菜的碘未录入。
2. 维 D / B12 / 叶酸：完全缺失，孕期与纯素只能给「未记录，建议检测/补充」的提示。
3. 嘌呤：只有标签级定性（高嘌呤关键词），没有 mg 值。
4. 脂肪酸细分：只有估算的 SFA/TFA，没有 MUFA/PUFA/Omega-3。
5. 品牌包装食品：原表覆盖有限，外卖/连锁餐品需要用户自定义。
